_No backend API dependencies — this screen renders static or locally-sourced content._

The Terms of Service screen does not call any OBP API endpoint. Content is either:

1. **Bundled** — shipped as a static string resource in `composeResources/` and loaded synchronously by `LegalContentRepository`.
2. **Remote-fetched** (optional future enhancement) — fetched from a static hosting URL and cached locally.

The `TermsOfServiceViewModel` reads from `LegalContentRepository` which abstracts the source. No DirectLogin token is required. The only network-contingent behavior is the `error` state triggered if a remote fetch fails; the Retry button re-invokes `onRetry()`.
