## Deployment Instructions

### Website Hosting

Upload `privacy-policy.html` and `terms-conditions.html` to your web server:

```
https://mifos.org/legal/privacy-policy.html
https://mifos.org/legal/terms-conditions.html
```

Ensure the server returns `Content-Type: text/html; charset=utf-8`.

### Google Play Store

1. In Play Console → App content → Privacy policy:
   - Enter URL: `https://mifos.org/privacy-policy`
2. In Data Safety section:
   - Fill form using `../DATA_SAFETY.yaml` as the authoritative data source
   - Key declarations: financial info, personal identifiers, auth credentials, crash logs (Android), performance data (Android)

### Apple App Store (App Store Connect)

1. In App Store Connect → App Privacy:
   - Privacy Policy URL: `https://mifos.org/privacy-policy`
2. Fill the Privacy Nutrition Labels using `../APP_PRIVACY.yaml`:
   - Data Linked to You: Financial Info, Contact Info, Identifiers, Credentials
   - Data Not Linked to You: None (no iOS crash/performance telemetry)
   - Data Used to Track You: None
3. No camera / photo-library declaration is needed — the app requests neither.

### In-App Links

Configure the following URLs in `BuildConfig` / app constants:

```kotlin
const val PRIVACY_POLICY_URL = "https://mifos.org/privacy-policy"
const val TERMS_CONDITIONS_URL = "https://mifos.org/terms"
```

## Regeneration

These files are regenerated by `/idea sync` Step 3F whenever the source documents change. Do not hand-edit — edits will be overwritten.

To manually regenerate:
1. Edit source files: `../PRIVACY_POLICY.md`, `../TERMS_CONDITIONS.md`
2. Run `/idea sync` or invoke the legal-deploy generation step
3. Verify size minimums (see table above)

Source hash tracking is recorded in `legal-config.json#regeneration.source_hash_fields`.
