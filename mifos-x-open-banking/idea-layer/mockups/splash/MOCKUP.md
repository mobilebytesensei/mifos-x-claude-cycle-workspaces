## Interaction Patterns

- **No user-initiated interactions.** The screen is fully display-only.
- Auto-navigation fires after 2 000 ms if `hasValidToken == false` → pushes Login.
- Auto-navigation fires immediately (0 ms) if `hasValidToken == true` → pushes Home (CONSUMER) or FO Dashboard (FIELD_OFFICER).
- The loading spinner is always animated during both `loading` and `navigating` states to signal progress.
- Tap events are swallowed (no interactive tap targets on this screen).

## Design Notes

**Color usage:**
- `primary` (the trust-blue brand hue) applied to logo tint, app name text, and loading spinner — establishes brand identity at first paint.
- `secondary` (neutral slate) used only for the tagline — creates visual hierarchy without competing with the primary brand hue. `tertiary` is deliberately NOT used here: as of DESIGN.md 1.3.0 it carries the warning / attention-needed semantic, and a tagline is neither.
- `surface` background (near-white) keeps contrast calm against the desaturated blue, consistent with the MD3 surface role.

**Typography:**
- `displayMedium` (45 sp, Roboto) for the app name gives the opening screen a typographic statement without shouting.
- `bodyLarge` (16 sp, Roboto) for the tagline maintains legibility at a smaller scale.
- No bold weight overrides — the weight pairing (display vs body) creates the hierarchy.

**Spacing:**
- All spacing uses the named 4 dp grid steps: `spacing.sm`=8, `spacing.lg`=24, `spacing.xl`=32.
- No horizontal padding on text components — centering alignment handles horizontal positioning.

**Accessibility:**
- The circular progress indicator carries a meaningful `label="Loading, please wait"` for screen readers.
- App name is marked as `role=heading` so TalkBack announces it as the page title.
- No minimum touch target requirements apply (no interactive elements).

**Animation:**
- Loading indicator is indeterminate — no duration or percentage values displayed.
- Transition from splash to login/home uses the standard shared-axis Z (material forward) navigation animation.
