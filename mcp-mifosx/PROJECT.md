## Description

Polyglot MCP server providing 4 implementations (Go, Java/Quarkus, Python/FastMCP, Rust/Tokio) that expose Apache Fineract banking operations as MCP tools. Stateless, RBAC-enforced, framework-agnostic. Supports SSE and stdio transports.
