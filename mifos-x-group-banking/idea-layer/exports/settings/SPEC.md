## Overview

Full-featured settings screen reached from the profile overflow menu on the personal-dashboard
(the authenticated member home). It reads and writes
MifosSave app preferences — language (English / Swahili / French / Hindi per FR-010), appearance
theme (Light / Dark / System), biometric-unlock and push-notification toggles — via
`multiplatform-settings` local key-value storage (DataStore), applying locale/theme changes
immediately. The ONLY network write is Change PIN, a dialog that hits Fineract
`PUT /self/user/updatePassword` through ktor-client. An About section shows the app version and
build; an outlined Logout button emits a confirmation-dialog event (the session clear happens after
confirmation in `settings-logout-dialog`). Biometric toggle is disabled when hardware is unavailable.

**Acceptance Criteria:**

- AC1: On mount, load preferences from DataStore (language, theme, biometric enabled + available,
       notifications, appVersion, buildNumber).
- AC2: Language selection persists to `multiplatform-settings` and re-applies the locale (no network).
- AC3: Theme selection persists and re-applies the Material theme immediately (no network).
- AC4: Biometric toggle persists only when `isBiometricAvailable`; when unavailable it is disabled
       and shows the "hardware not available" sub-label (no write).
- AC5: Notifications toggle persists the preference (no network).
- AC6: Change PIN row opens the dialog (`isChangingPin=true`); Update PIN calls `change_pin`
       — 200 → close + success snackbar, 400 → inline error, 401 → clear session + navigate to login.
- AC7: Logout emits `ShowLogoutDialog`; actual session clear runs after confirmation.
- AC8: About row shows `{appVersion} ({buildNumber})`.
