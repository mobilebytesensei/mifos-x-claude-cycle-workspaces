## Overview

Paginated roster of members belonging to a savings group. Loads the first page on
mount via `get_group_members` (`GET /groups/{groupId}/clients`) with offset pagination
(page_size=20), appending pages as the user scrolls. `cmp-network-monitor` detects
offline state and serves cached SQLDelight rows (120 s stale-while-revalidate) while
revalidating in the background. Each row renders the member's avatar (photo or initials
fallback), name, savings balance, a color-coded role chip (Chairperson / Treasurer /
Secretary / Member), and a loan-status badge (Active / None / Overdue). Tap or
swipe-to-start navigates to `member-profile`; a FAB (and the empty-state CTA) navigates
to `member-add`; a top-bar Invite action navigates to `member-invite` (organizer issues a
single-use invite code). Covers FR-002.

**Acceptance Criteria:**

- AC1: On mount call `get_group_members(groupId, limit=20, offset=0)`; on success show
       Content, on empty response show Empty, on error show Error.
- AC2: Scroll-to-end triggers `OnLoadMore` only when `hasMorePages && !isLoadingMore`;
       appends the next page and advances `currentOffset`.
- AC3: Role chip is color-coded per role enum (Chairperson=primaryContainer,
       Treasurer=secondaryContainer, Secretary=tertiaryContainer, Member=surfaceVariant).
- AC4: Loan-status badge is color-coded (Active=green, Overdue=red, None=neutral).
- AC5: Pull-to-refresh invalidates cache and resets pagination to offset 0.
- AC6: Offline (`cmp-network-monitor`) serves cached members with a "Showing cached
       members" message; auth 401 redirects to login.
- AC7: Empty state (zero members) shows the group_add illustration + Add Member CTA.
- AC8: Top-bar Invite action (`OnInviteMember`) navigates to `member-invite` with
       `groupId` (member-onboarding-flow invite path).
