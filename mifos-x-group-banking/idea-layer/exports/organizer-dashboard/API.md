This single companion endpoint replaces three raw Fineract calls
(`/staff/{id}/summary` + `/centers` + `/journal-entries`). Identity and group membership are
resolved server-side from the auth token via `dt_member_role` — no `staffId` param is sent.

## Offline Behaviour

`organizer_dashboard_cache` serves the last response (300 s stale-while-revalidate) when
`cmp-network-monitor` reports offline; a "Showing cached data" message is surfaced and
revalidation runs when connectivity returns. Pull-to-refresh forces a cache-bypassing fetch.

## Error Type Map

| Error | Behaviour |
|---|---|
| `network.offline` | Serve cached summary + message (retryable) |
| `401 Unauthorized` | `Auth` → redirect to group-list / login |
| `403 Forbidden` | Not an organizer in any group |
| `500 Server` | `Server` → error banner + retry |
