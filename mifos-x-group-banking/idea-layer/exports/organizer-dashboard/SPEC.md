## Overview

Organizer-per-group hub surface, reached by the unified identity (single login) whenever the
session user's `dt_member_role` resolves at least one group where they hold an organizer /
treasurer / chairperson role — there is NO separate admin client type. A single companion API
call (`GET /companion/organizer/dashboard`, replacing three raw Fineract calls) returns KPIs
scoped to "my groups" (not all-branch): My Groups count, Members, Share-Outs Due, Meetings
Today. The response is cached in SQLDelight (`organizer_dashboard_cache`) with
stale-while-revalidate (300 s) via a `cmp-network-monitor`-aware repository so the dashboard
renders offline. Quick-nav tiles route to `group-list`; the Field Officer tile is an optional
v1.1 tier shown only when `fieldOfficerEnabled=true`. This is the app entry point (home tab).

**Acceptance Criteria:**

- AC1: On mount call `get_organizer_dashboard` (identity resolved server-side from token); on
       success show Content, on error show Error.
- AC2: KPIs are organizer-scoped ("my groups"): myGroupCount, totalMembers,
       pendingShareOutCount, meetingsTodayCount.
- AC3: Share-Outs Due KPI value + card border turn error-red when `pendingShareOutCount > 0`.
- AC4: Field Officer quick-nav tile is visible ONLY when `fieldOfficerEnabled=true`; tapping it
       navigates to `field-officer-dashboard` (guarded by the same flag).
- AC5: Today's Schedule lists meetings; tapping a row navigates to `group-list` filtered by that
       `groupId`; an empty-schedule label shows when `todaySchedule.isEmpty()`.
- AC6: Every KPI card + the All Groups tile + the empty-state CTA navigate to `group-list`.
- AC7: Pull-to-refresh invalidates cache and re-fetches; offline serves cached data with a
       "Showing cached data" message; 401 → Auth redirect to group-list.
- AC8: Notifications action is deferred — emits a snackbar (in-app centre ships later), no nav.
