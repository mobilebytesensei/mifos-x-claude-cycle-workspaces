## Request / Response Details

### POST /companion/auth/self-register (COMP-AUTH-001)

Self-registration bridge that creates a companion user account and a linked Fineract
client in one atomic request. No authentication token required.

**Request**

| Field | Type | Required | Description |
|---|---|---|---|
| name | String | yes | Display name |
| emailPhone | String | yes | Email or E.164 phone (server normalises) |
| password | String | yes | Min 8 chars |

**Response** (`object`)

| Field | Type | Description |
|---|---|---|
| userId | String | Companion user ID |
| sessionToken | String | Bearer token |
| tokenExpiresAt | String | ISO-8601 expiry |
| groupMemberships | List<GroupMembership> | Empty for new registrations |

**Errors**

| Code | Meaning |
|---|---|
| 400 | Validation error — missing or malformed fields |
| 409 | Account with this email or phone already exists |
| 500 | Server error |

**Cache:** none — write endpoint.

---

### POST /companion/auth/login (COMP-AUTH-002)

Per-user authentication that validates credentials and returns a session token plus the
full group membership list with role per group.

**Request**

| Field | Type | Required | Description |
|---|---|---|---|
| emailPhone | String | yes | Registered email, E.164 phone, or username |
| password | String | yes | Password |

**Response** — same shape as COMP-AUTH-001 (userId, sessionToken, tokenExpiresAt,
groupMemberships).

**Errors**

| Code | Meaning |
|---|---|
| 401 | Invalid credentials |
| 429 | Too many failed attempts — rate-limited |
| 500 | Server error |

**Cache:** none — write endpoint.

---

### GET /companion/auth/me (COMP-AUTH-003)

Fetch the authenticated user profile and all group memberships with role per group.
Called after biometric unlock to refresh the session.

**Request** — no body; Bearer token in header.

**Response** (`object`)

| Field | Type | Description |
|---|---|---|
| userId | String | Companion user ID |
| name | String | Stored display name |
| emailPhone | String | Registered credential |
| groupMemberships | List<GroupMembership> | All groups the user belongs to |

**Errors**

| Code | Meaning |
|---|---|
| 401 | Session token invalid or expired |
| 500 | Server error |

**Cache:** TTL 300 s, stale-while-revalidate; offline → show cached. Invalidated on logout.

## Cache Strategy

Default `network-first`; offline `show_cached`. Only `companion_me` is cacheable (300 s
SWR); both write endpoints are uncached.

## Offline Behaviour

Auth endpoints require active connectivity. No offline mutation or token refresh is
supported. `SessionStore` serves the cached `sessionToken` for subsequent in-session API
calls while online; on expiry the user is redirected to login-signup.

## Error Type Map

| Error Class | `LoginSignupError` | Behaviour |
|---|---|---|
| `400 Bad Request` | `WeakPassword` / validation | Show field-level `validationErrors` map |
| `401 Unauthorized` | `InvalidCredentials` | Show top-level error banner |
| `409 Conflict` | `AccountExists` | Show "Already registered" inline error |
| `429 Rate Limited` | `Server` | Show "Too many attempts, try again later" banner |
| `network.offline` | `Network` | Block submit — "Requires internet connection" |
| `500 Server` | `Server` | Show retry banner |
| biometric hardware failure | `BiometricFailed` | Fall back to manual sign-in |
