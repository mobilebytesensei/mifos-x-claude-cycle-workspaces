## Request / Response Details

### GET dt_meeting_record/{groupId} (summary)
Params `groupId: Int` (nav_params), `meetingNumber: Int` (nav_params). Returns a
`PreviousMeetingDetailResponse` with metrics, savingsBreakdown, attendanceRecords, and loanItems.
`404` → error state; `5xx` → serve cached data if available.

### GET dt_meeting_attendance/{meetingId} (attendance)
Param `meetingId: String` (nav_params). Returns `List<AttendanceRecord>`. `404` → empty list.

### GET dt_loan_vote/{loanId} (unresolved votes)
Param `loanId: String`. Returns a `LoanVoteRecord` (or none). `404` → no pending votes.

## Offline Behaviour

The `meeting_records` SQLDelight table (`LocalMeetingDao`) serves cached recaps (300 s
stale-while-revalidate) when `cmp-network-monitor` reports offline; the recap renders fully from
cache. Background revalidation runs when connectivity returns. There are no writes.

## Error Type Map

| Error | Behaviour |
|---|---|
| `network.offline` | Serve cached recap from LocalMeetingDao |
| `404` (record) | Error state ("Could not load previous meeting data") |
| `404` (attendance) | Empty attendance list |
| `404` (loan votes) | No pending votes |
| `5xx` | Show cached data if available, else error state |
