## Request / Response Details

### GET /clients/{clientId} (identity)

Path `clientId: Long` (from nav_params). Response `object`:
`id: Long, displayName: String, firstname: String, lastname: String, mobileNo: String,
imagePresent: Boolean, status: {id, value}, activationDate: String, officeId: Long`.

### GET /clients/{clientId}/accounts (savings + loans)

Path `clientId: Long`. Response `object`:
- `savingsAccounts[]`: `{ id, productName, accountNo, balance: Double, status: {id, value} }`
- `loanAccounts[]`: `{ id, productName, accountNo, status: {id, value},
   summary: { principalDisbursed, principalOutstanding, totalOverdue } }`

### GET /datatables/dt_member_role/{clientId} (role)

Path `clientId: Long`. Response `array` of `{ role: String, groupId: Long, assignedDate: String }`.

### PUT /datatables/dt_member_role/{clientId} (role write — chairperson only)

Path `clientId: Long`. Body `{ role: String, groupId: Long, assignedDate: String }`.
Response `object { resourceId: Long }`. Gated by `cmp-network-monitor`; only reachable when
`isCurrentUserChairperson`.

## Offline Behaviour

`members` (300 s) and `member_accounts` (120 s) serve cached rows under stale-while-revalidate
when `cmp-network-monitor` reports offline; a "Showing cached profile" message is surfaced.
The role write is blocked offline.

## Error Type Map

| Error | Behaviour |
|---|---|
| `network.offline` | Serve cached profile + message (retryable) |
| `401 Unauthorized` | `Auth` → redirect to login |
| `403 Forbidden` | Blocked (role write: caller not chairperson) |
| `404 Not found` | `NotFound` — member/role record not found |
| `400` (role write) | Invalid role value |
| `500 Server` | `Server` / `RoleUpdateFailed` → retry |
