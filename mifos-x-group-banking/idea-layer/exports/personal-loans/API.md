## Offline Behaviour

The `loans` SQLDelight table serves cached rows (180 s stale-while-revalidate) when
`cmp-network-monitor` reports offline; revalidation runs over the Fineract REST client when
connectivity returns. Pull-to-refresh invalidates the cache and forces a fresh fetch.
