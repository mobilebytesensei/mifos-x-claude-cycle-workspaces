## Common Mismatch Patterns

| Pattern | Problem | Fix |
|---------|---------|-----|
| Generic `id` vs specific `movie_id` | DTO expects `@SerialName("movie_id")`, RPC returns `id` | Alias: `SELECT m.id AS movie_id` |
| Missing prefix | DTO expects `out_mood_id`, RPC returns `mood_id` | Alias: `SELECT mood_id AS out_mood_id` |
| Type casting | DTO `String`, RPC returns `UUID` | Cast: `SELECT id::TEXT AS movie_id` |
| NULL for non-nullable | DTO `val title: String`, RPC returns `NULL` | Fix: `COALESCE(title, '')` or make DTO nullable |

## Validation Query

```sql
-- Generate this mapping automatically from pg_proc
SELECT
    p.proname AS rpc_function,
    a.attname AS column_alias,
    pg_catalog.format_type(a.atttypid, a.atttypmod) AS column_type,
    NOT a.attnotnull AS is_nullable
FROM pg_proc p
JOIN pg_namespace n ON p.pronamespace = n.oid
JOIN pg_type t ON p.prorettype = t.oid
LEFT JOIN pg_attribute a ON a.attrelid = t.typrelid AND a.attnum > 0
WHERE n.nspname = 'public'
AND p.proname = '{function_name}'
ORDER BY a.attnum;
```
