# DTOs Index — Mifos-X Back-Office Next-Gen (mifos-x-backoffice-next-gen)

> 52 DTOs | all Fineract REST (`origin: rest`) | 32 response · 20 request

Backend is the Apache Fineract `/v1/*` REST surface (consumed as-is; no server-layer built).
Every read is CACHE_FIRST_SWR (offline-first); every mutation is queued to the durable outbox and
replayed exactly-once via `POST /v1/batches`. All DTOs are project-specific and are NOT shadows of
`templates/shared/common-dtos.yaml` (ErrorEnvelope / PaginationCursor / PaginatedEnvelope / AuthSession).

Generated by `/idea-data-dtos` (bootstrap-from-screens). Source of truth for API shapes across all
features that declare formal `dto:` / `body:` refs (8 of 21). The remaining 13 features currently
express response shapes as informal `response_type:` annotations (not formal DTO refs) and are out of
scope for this pass; they materialize DTOs when their `api.yaml` promotes those to `dto:`/`body:` refs.

Naming note: `CommandProcessingResult`↔`CommandProcessingResultDto` and `BatchResponse`↔`BatchResponseDto`
are identical Fineract shapes referenced under both spellings across features — both registered so every
ref resolves. A future enrich pass may normalize the `api.yaml` refs to one canonical spelling.
