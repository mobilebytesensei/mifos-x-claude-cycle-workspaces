## Error Handling

All endpoints follow standard error mapping:
- 401 -> Auth error (redirect to signin)
- 403 -> NoAuthorization -> permission-capability-engine drift refresh + re-resolve (the checker's access may have changed; drop to nearest visible ancestor, not a crash)
- 404 -> NotFound error
- 422 -> Validation error (command rejected)
- 500 -> Server error (retryable; error state + Retry)
