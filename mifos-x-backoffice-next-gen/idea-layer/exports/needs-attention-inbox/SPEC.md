## Flow Logic (5 decisions)

| Decision | Condition | True Path | False Path | Impl |
|----------|-----------|-----------|------------|------|
| Aggregation result | fan-in returns ≥1 item across ≥1 permitted category | content (grouped + ranked) | empty ("all caught up" + Sync now) | fold four permission-filtered Flows → NeedsAttentionScreenState |
| Source vs hard failure | a single remote source errors | content + per-group retry strip (rest still renders) | error ONLY when local Room read throws before any source contributes | per-source error_state=content; local outbox error_state=error |
| Category permission gate | user holds the category's permission | category contributes rows | category omitted entirely from the feed | PermissionEvaluator gate per source at aggregation time |
| Retry replay permission | queued command's permission still valid on replay | re-enqueue w/ fresh idempotency key → POST /v1/batches | surface BLOCKED_PERMISSION_REVOKED (never silently dropped) | replay revalidates per-command permission |
| Approve authorization | user canCheck(action,entity) or holds CHECKER_SUPER_USER | inline Approve shown → POST /v1/makercheckers/{id}?command=approve | no Approve control on that row | per-entry client gate above the server checker gate |
