## Flow Logic (4 decisions)

| Decision | Condition | True Path | False Path | Impl |
|----------|-----------|-----------|------------|------|
| NavRoster has ≥1 root | PermissionEvaluator.hasAnyFamily() returns true for at least one module | assembled (render NavRoster adaptive) | empty (zero permitted modules — contact admin) | fold evaluated roots; emit ScreenState |
| ALL_FUNCTIONS | PermissionSet contains ALL_FUNCTIONS umbrella code | short-circuit — all 17 roots visible, no family evaluation | evaluate each root's permission_family via CapabilityMap | CapabilityMap check on hasAllFunctions flag |
| PermissionSet readable | PermissionStateHolder emits the set within cold-start window | assembled | error ("Could not assemble your workspace") + retry | StateFlow collection with timeout |
| 403-drift refresh | permission-capability-engine emits a new PermissionSet | re-run AssembleNavRoster; update NavRoster in-place (no app restart) | — (one path only) | StateHolder.collect triggers reassembly |
