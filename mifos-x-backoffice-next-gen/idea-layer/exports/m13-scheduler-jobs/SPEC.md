| Offline read | offline with a cached roster + status | loading → no_network (cached served, mutating controls disabled) | loading → error (no cache) | fromCache flag; online-only controls disabled with reason |

| Permission drift | run/edit/toggle returns 403 NoAuthorization | route to permission-capability-engine refresh + prune denied controls live | continue | refreshPermissions(); 'Your access has changed' toast, screen stays alive |
