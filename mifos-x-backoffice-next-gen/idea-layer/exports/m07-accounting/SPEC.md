## Flow Logic (6 decisions)

| Decision | Condition | True Path | False Path | Impl |
|----------|-----------|-----------|------------|------|
| is_balanced | debitTotal == creditTotal AND debitTotal > 0 | Enable Post → enqueue CREATE_JOURNALENTRY | Disable Post; balance indicator 'Out of balance by X' (red) | Client-side balance gate BEFORE the network |
| has_permission(cmd) | user holds gated_permission | Show/enable control | Hide (HIDE) or disable (DISABLE) per on_denied | permission-capability-engine, fail-closed |
| online | connectivity available | Replay outbox immediately | Queue with 'queued offline' chip; replay on reconnect | offline-sync-engine durable outbox, durable idempotency key |
| maker_checker | tenant maker-checker on for command | Show 'Submitted for approval' badge (not Posted) | Entry shown Posted after 2xx | CommandProcessingResult with commandId + empty changes |
| server_rejected | batch response = FAILED (unbalanced / invalid GL / closed period) | Route to needs-attention-inbox with server_error | Entry appears in history | Batch-response triage; never silently dropped |
| period_closed | entryDate on/before a GL closure | Server rejects → needs-attention 'period closed'; stays unposted | Posts normally | gl_closures cache warns; server enforces |
