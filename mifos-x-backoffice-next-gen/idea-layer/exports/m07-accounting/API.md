## Error Handling

All endpoints follow standard error mapping:
- 401 -> Auth error (redirect to signin)
- 403 -> Permission drift -> refreshPermissions() (denied controls pruned live)
- 404 -> NotFound error
- 422 -> Validation error (unbalanced entry / invalid GL / closed period surface here or as 400)
- 500 -> Server error (retryable)

Mutating endpoints are enqueued to the durable outbox (draft_outbox) with a durable idempotency key and replayed exactly-once via `POST /v1/batches` — a retry never double-posts. Server-rejected commands are routed to `needs-attention-inbox`, never silently dropped.
