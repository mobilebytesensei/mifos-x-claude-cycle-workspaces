| Cache vs error | offline or list/360 fetch failed | no-network (serve cached list/360 + offline banner) | error + Retry (no cache) | CACHE_FIRST_SWR SourceOfTruth over Room |
| Submit path | network available at command submit | content (command applied online) | content + 'queued offline' chip (durable outbox) | enqueue to outbox → replay via POST /v1/batches enclosingTransaction |
| Maker-checker | command returns commandId with empty changes | 'Submitted for approval' badge (status not flipped optimistically) | optimistic content refresh | tenant maker-checker gate |
| Permission drift | list/command returns 403 NoAuthorization | route to permission-capability-engine refresh + re-resolve (prune denied controls) | continue | refreshPermissions(); screen stays alive |
