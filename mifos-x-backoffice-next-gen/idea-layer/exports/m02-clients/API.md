## Error Handling

All endpoints follow standard error mapping:
- 401 -> Auth error (redirect to signin)
- 403 -> NoAuthorization -> permission-capability-engine drift refresh + re-resolve (denied controls pruned, not a crash)
- 404 -> NotFound error
- 422 -> Validation error (surfaced on the template form / needs-attention)
- 500 -> Server error (retryable; error state + Retry)

- `list_*` / `get_*` are safe reads (`safe_get`) served CACHE_FIRST_SWR so the list + 360 + sub-resource tabs render offline from Room.
