## Flow Logic (5 decisions)

| Decision | Condition | True Path | False Path | Impl |
|----------|-----------|-----------|------------|------|
| Catalog has runnable reports | list_reports returns reports the operator may run | content | empty ("no runnable reports in this office") | client-filter catalog Store5 stream → ScreenState |
| Report run path | GET /v1/runreports resolves | running → result (fresh online run, or cached result for same params offline) | running → error (400 param / 403 authz / no cache offline) + Retry | CACHE_FIRST_SWR over report_results_cache |
| Search matched | POST /v1/search/advance returns hits | content (ranked hits rendered, each deep-links) | empty ("nothing matched") | CACHE_FIRST_SWR over search_results_cache |
| Audit pane visible | operator holds READ_AUDIT | Audit tab shown; trail + filter template load | Audit tab hidden entirely (onDenied HIDE, fail-closed) | permission-capability-engine PermissionEvaluator gate |
| Permission drift | any read returns 403 NoAuthorization | refreshPermissions() → prune denied panes/reports, re-resolve, retry | continue | drift protocol; screen stays alive, never crashes |
