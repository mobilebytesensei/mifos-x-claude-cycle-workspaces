## Flow Logic (6 decisions)

| Decision | Condition | True Path | False Path | Impl |
|----------|-----------|-----------|------------|------|
| Valid PermissionSet | login returns valid permissions[] AND not shouldRenewPassword AND not 2FA-required | content (build capability surface) | unauthenticated (route to login-tenant) | normalize permissions[] → PermissionSet; else GoToLogin |
| Map build | CapabilityMap present + checksum-valid + resolves | content | error (retain encrypted set; offer Retry) | checksum-verify capability-map.json; RetryCapabilityBootstrap from retained set |
| Umbrella short-circuit | permissions[] contains ALL_FUNCTIONS | grant all 17 module roots without enumeration | per-group gate each root | ALL_FUNCTIONS_READ never grants a mutation (canDo uses ALL_FUNCTIONS only) |
| Unmapped id | capability id has no CapabilityMap entry | HIDDEN (fail closed) | resolve VISIBLE / DISABLE(reason) | MapCoverageTest flags the gap as a CI build failure |
| Permission drift | server returns 403 NoAuthorization on a previously-allowed command | refresh via password-less role fallback + fingerprint compare + re-resolve + prune now-denied UI; notify once | continue | never crash; never trust cache over server |
| Fingerprint change | rebuilt PermissionSet fingerprint differs from current | atomic swap + re-resolve CapabilityMap; prune now-denied nav roots + controls | keep current set (no re-resolve) | fingerprint = sha256(sorted(codes)) |
