| Cache vs error | offline or generate failed | no-network (serve cached sheet) | error + Retry (no cache) | CACHE_FIRST_SWR SourceOfTruth over Room |
| Submit path | network available at submit | submitting → content (online batch applied) | submitting → queued-offline (durable outbox) | POST /v1/batches enclosingTransaction vs outbox enqueue |
| Maker-checker | saveCollectionSheet returns commandId without resourceId | "Submitted for approval" badge (not applied) | optimistic content refresh | tenant maker-checker gate |
| Permission drift | generate/save returns 403 NoAuthorization | route to permission-capability-engine refresh + re-resolve | continue | prune now-denied controls, keep sheet alive |
