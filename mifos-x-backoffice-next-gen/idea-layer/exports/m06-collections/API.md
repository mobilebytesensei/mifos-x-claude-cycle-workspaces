## Error Handling

All endpoints follow standard error mapping:
- 401 -> Auth error (redirect to signin)
- 403 -> NoAuthorization -> permission-capability-engine drift refresh + re-resolve (not a crash)
- 404 -> NotFound error
- 422 -> Validation error
- 500 -> Server error (retryable; error state + Retry)

Notes:
- `generate*` are reads (`command=generate` returns data, mutates nothing) — CACHE_FIRST_SWR so a 30-member sheet renders offline under 1s.
- `save*` + `batch_submit` are enqueued through the offline outbox with a durable idempotency key and replayed as ONE all-or-nothing batch (`POST /v1/batches?enclosingTransaction=true`) — exactly-once, zero double-post.
- `save*` are maker-checker aware: a `commandId` without a `resourceId` = submitted-for-approval (not applied optimistically).
