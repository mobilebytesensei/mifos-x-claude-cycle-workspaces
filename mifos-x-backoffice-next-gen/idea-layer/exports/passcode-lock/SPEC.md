## Flow Logic (5 decisions)

| Decision | Condition | True Path | False Path | Impl |
|----------|-----------|-----------|------------|------|
| Mode at entry | mode == SETUP (entered from M17 settings) | show "Set your passcode" header; advance to Confirm on 6 digits | mode == LOCKED (cold start / background) → "Enter your passcode" + user info | PasscodeMode enum |
| PIN confirm match | confirmDigits == currentDigits | hash(PIN) → persist passcode_hash; passcode_enabled=true; emit UnlockSuccess → shell | shake + "PINs don't match"; auto-reset to Setup after 1.5s | bcrypt compare in-memory |
| PIN unlock match | bcrypt(entered) == stored passcode_hash | emit UnlockSuccess → shell | shake + "Incorrect PIN · {remaining} attempts remaining"; failedAttempts++ | bcrypt compare in-memory |
| Failed attempts threshold | failedAttempts >= 5 | Locked_Out; lockout duration = 30s × 2^(tier-1); countdown chip shown | Locked state continues (remaining = 5 - failedAttempts) | in-memory counter + lockedUntil persisted |
| Biometric available | biometric_lock_enabled=true AND OS biometric enrolled | show biometric_button on lock screen; trigger BiometricPrompt on tap | biometric_button hidden; PIN-only unlock | BiometricManager.canAuthenticate check on mount |
