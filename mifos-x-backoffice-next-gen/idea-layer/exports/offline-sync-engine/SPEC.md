## Flow Logic (6 decisions)

| Decision | Condition | True Path | False Path | Impl |
|----------|-----------|-----------|------------|------|
| Outbox has work | RoomSubmitOutbox has PENDING/RETRYING entries | content (list N pending, Sync now enabled) | idle (up-to-date) or empty (no queue + no prior delta) | fold RoomSubmitOutbox observe() Flow → ScreenState |
| Submit path | network available at drain | syncing → idle/content (online batch applied) | syncing → no_network (commands stay PENDING) | POST /v1/batches enclosingTransaction=true vs stay queued |
| Batch result | POST /v1/batches accepted | syncing → idle (zero rejects, SUBMITTED) | error (rejected → needs-attention-inbox + Review failed) | BatchResponse per-request statusCode fan-out |
| Idempotency retry | retry_failed re-drains a FAILED entry | replay reuses the ORIGINAL durable idempotency key (no double-post) | first attempt mints the key | Idempotency-Key header per outbox entry (Room v11) |
| Delta-pull scope | trigger_delta_pull with authenticated officeId | GET /v1/audits scoped to office/portfolio; advance FetchedAt watermark | delta_pull.failed → retry w/ backoff (cached reads still served) | Synchronizer.changeListSync over lastModifiedSince feed |
| Session expiry | replay/delta returns 401 auth.session_expired | route to permission-capability-engine re-auth; replay revalidates | continue drain | re-auth then resume outbox drain |
