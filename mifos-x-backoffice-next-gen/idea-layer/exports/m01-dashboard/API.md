## Error Handling

All endpoints follow standard error mapping:
- 401 -> Auth error (redirect to signin)
- 403 -> NoAuthorization -> permission-capability-engine drift refresh + re-resolve (prune the now-denied tile, keep the rest alive; not a crash)
- 404 -> NotFound error
- 422 -> Validation error
- 500 -> Server error (retryable; isolated to the one tile → partial-tile-error + per-tile Retry)
