## Capability Contracts

### resolve_tile_roster
`PermissionEvaluator.observe(tileId): Flow<CapabilityState>` per fixed tile; VISIBLE tiles form the roster; unmapped/denied → HIDDEN (fail-closed); `ALL_FUNCTIONS_READ` never yields a mutating quick-action tile. Permission `none`. Errors: `tile_roster_resolve_failed`, `retained_permission_set_absent`.

### hydrate_kpi_tiles
GET /v1/runreports/{reportName} (R_officeId) → `StoreFactory.createStore` + Room SourceOfTruth + `asScreenStream(CACHE_FIRST_SWR)` per tile_id; `ReportResult` → headline KPI value. Permission `REPORTING_SUPER_USER`. Errors: `tile_load_failed`, `report_unavailable`.

### hydrate_collections_tile
GET /v1/collectionsheet?staffId&transactionDate → cached `CollectionSheet` summary (due amount + count) for the field officer's route. Permission `READ_COLLECTIONSHEET`. Errors: `tile_load_failed`.

### hydrate_approvals_tile
GET /v1/makercheckers?makerCheckerable → pending-approval count self-scoped to entries the user can approve; present iff `hasAnyChecker`. Permission `CHECKER_SUPER_USER`. Errors: `tile_load_failed`.

### hydrate_activity_feed
GET /v1/notifications (poll + mark-read) → recent-activity rows with entity deep-links; no special permission required. Permission `none`. Errors: `tile_load_failed`.

| Per-tile hydration | every permitted tile's fetch succeeds (live or cache) | content | partial-tile-error (inline error + Retry on the failing card only; the rest render) | per-tile StoreFactory.stream(tileId) CACHE_FIRST_SWR; single-tile failure isolated |
| Connectivity | offline at load | no-network (each permitted tile shows its last cached value + offline banner; tapping still navigates) | content (live tile values) | cmp-network-monitor; CACHE_FIRST_SWR SourceOfTruth serves cache |
| Retry path | retry_failed_tile re-fetch succeeds | partial-tile-error → content (every tile now has a value) | partial-tile-error (that tile still failing — inline placeholder kept) | DashboardTileRepository.refetch(tileId) re-issues only the failed tile's Fineract call |
