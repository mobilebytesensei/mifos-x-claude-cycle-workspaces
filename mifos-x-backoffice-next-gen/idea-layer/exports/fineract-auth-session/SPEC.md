## Capabilities

- **basic_auth_login** — POST /fineract-provider/api/v1/authentication?tenantIdentifier={tenant} with {username,password}; build basicToken=base64('username:password') and store Session{baseUrl,tenant,basicToken,userId,permissions}; every subsequent request carries Authorization: Basic + Fineract-Platform-TenantId.
- **session_persist_restore** — Session persisted encrypted via multiplatform-settings secure variant (Keystore/Keychain); restored verbatim on cold start (offline-capable); cleared atomically on logout / 401 drop.
- **authenticated_fineract_client** — a Ktorfit client over core-base/network with a dynamic base-URL provider + auth+tenant interceptor; a 401 emits an unauthorized event that drops the session and routes to login — the single transport every data feature rides on.
