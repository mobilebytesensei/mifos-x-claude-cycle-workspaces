## Screen Intent

The organization reference-data admin surface, an entity-tabbed master/detail across **Offices (hierarchy tree) · Staff · Currencies · Holidays · Working Days · Funds · Payment Types · Codes & Code-Values**, plus a Bulk Loan Reassignment tool. Each New/Edit entry point is VISIBLE/enabled per the user's exact `{ACTION}_{ENTITY}` permission (fail-closed HIDE for create FABs; DISABLE-with-reason where a stage is meaningful to see). Reference edits are **ONLINE-ONLY** (never deferred-sync); rejected commands route to `needs-attention-inbox`; cached reference data keeps offline dropdowns populated.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title "Organization", menu/back leading.
- **Bottom navigation** — visible as a module root. **FAB / actions** — per-entity New buttons gated on CREATE_{ENTITY}.
- **Offline banner** — reference data served from cache; config writes disabled offline.

### State: `loading` — reference shimmer
Header + entity tabs stay; rows render as `shimmer-skeleton`; cached reference data preserved so dropdowns stay populated.

### State: `empty` — tab has no rows
Illustration + tab empty message + a "New …" CTA (only with the matching CREATE_{ENTITY}).

### State: `submitting` — reference create/edit queuing
A create/edit or bulk reassignment enqueues with a "Saving…" / "Submitted for approval" chip. Reference edits ONLINE-ONLY — offline the control is disabled ("connect to edit configuration").

### State: `action-disabled` — permission missing
A user lacking a mutation (e.g. BULKREASSIGN_LOAN / ACTIVATE_HOLIDAY) sees the control disabled with a reason chip ("Requires BULKREASSIGN_LOAN — ask your supervisor").

### State: `error` — fetch/command failed
Server error verbatim + Retry; rejected commands route to `needs-attention-inbox`; cached reference data stays usable.
