## Screen Intent

A read-only, three-pane console: **Reports** (the per-report-gated catalog filtered to reports the operator may run — `READ_{reportName}` or `REPORTING_SUPER_USER` — with parameterised run + Table/Pentaho/Chart output and CSV/PDF export to the share sheet), **Search** (global query box deep-linking hits into their module), **Audit** (the filterable audit trail, hidden entirely unless `READ_AUDIT` is held). No mutating controls appear anywhere. A 403 re-fetches the PermissionSet and prunes any pane/report the operator can no longer read.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title "Reports & Audit", menu/back leading.
- **Bottom navigation** — visible as a module root. **Offline banner** — cached catalog/results served; runs resolve cached same-param results.

### State: `loading` — catalog/page shimmer
Header + tabs stay; catalog / audit page render as `shimmer-skeleton` (CACHE_FIRST_SWR); Search starts idle.

### State: `running` — report executing
Report params entered → `GET /v1/runreports/{reportName}` executes online (or resolves the cached same-param result offline); progress indicator while the result assembles.

### State: `result` — output shown
The report output renders as Table / Pentaho / Chart, or the audit-detail / search-result set; an **Export** control renders to CSV/PDF and hands to the platform share sheet.

### State: `empty` — nothing in pane
No runnable reports, a search that matched nothing, or an empty audit filter → illustration + hint to broaden (no create CTA — read-only).

### State: `error` — fetch failed
400 validation / 403 authorization + Retry; a 403 re-fetches the PermissionSet and prunes pruned panes/reports live.

## Accessibility & Density Notes

- Entire surface is read-only — no mutating controls; Audit pane hidden (not greyed) without READ_AUDIT.
- Export hands off to the platform share sheet (CSV/PDF); result tables use Roboto Mono numerics for alignment.
- A 403 prunes panes/reports live via the drift protocol — the UI never offers a report the server will reject.
