## Screen Intent

The authenticated app-shell host that wraps every module. After sign-in it reads the resolved `PermissionSet` from `PermissionStateHolder` and builds a `NavRoster` containing only the module roots the user is permitted to see — **fail-closed: HIDDEN (never gray-out) when zero codes in the module's permission family (§4.7 Tier 1)**. Adaptive form factor: phone → bottom bar (≤5 priority roots); tablet → navigation rail (all permitted roots, labels collapsed); desktop → permanent navigation drawer (all permitted roots + labels). `ALL_FUNCTIONS` umbrella (Super user) short-circuits to all 17 roots visible with no family evaluation. Re-assembles automatically on any `PermissionSet` refresh (403-drift, re-auth, server switch) without restarting the app.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title of the active module (driven by `activeModuleId`). Hidden during the full-screen lock states (passcode-lock); visible here.
- **Bottom navigation** — phone: up to 5 priority roots rendered as `NavigationBar` items; active item carries a selection pill. Tablet/desktop: replaced by rail or permanent drawer.
- **FAB** — not used by the assembler itself; each module may declare its own FAB within the content pane.
- **Drawer header chip** — desktop/tablet only: `{currentUserName} · {officeName}` chip. Tapping opens `permission-set-detail`.
- **Snackbar** — one-time notification when the nav roster is updated after a 403-drift refresh: `"Your access was updated — some areas may have changed."`

## Accessibility & Density Notes

- Nav root items carry `accessibility_label: "Navigate to {moduleLabel} module"` — screen readers announce each root by module name.
- Absent roots produce no ARIA nodes — hidden, not announced.
- Active root carries `aria-selected: true` for the selection pill.
- On 403-drift refresh, a single snackbar ("Your access was updated") fires once; the nav roster rebuilds without user action.
- The `shimmer` resolving state is `<100ms` on warm start (80ms typical) — effectively invisible to the user; no loading indicator is shown separately.
- Desktop drawer is permanently open; tablet rail collapses labels (icon-only) to save width; phone bottom bar is constrained to 5 items with overflow into the drawer.
