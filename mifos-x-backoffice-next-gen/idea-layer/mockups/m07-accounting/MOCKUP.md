## Screen Intent

The accounting workspace: the Chart-of-Accounts tree grouped by type (Asset / Liability / Equity / Income / Expense) with running balances, the recent-journal-entries list (reference, description, debit/credit totals, posted/pending status), and a permission-gated command bar — **compose & post a manual journal entry** (with a live debit==credit **balance gate**), reverse, create GL account, close period, run periodic accruals, map financial activities. Journal posting queues to the durable outbox exactly-once; a rejected posting routes to Needs-Attention.

- **Top app bar** — small M3, `surface`, title "Accounting", menu/back leading.
- **Bottom navigation** — visible as a module root. **FAB** — `create_gl_account_fab` (CREATE_GLACCOUNT).

### State: `balancing` — composing a journal entry
Debit + credit lines entered/edited with a live debit-total vs credit-total. **Post is DISABLED until debits == credits** (the client-side balance gate); an unbalanced difference shows in `error` red with the delta ("Out of balance by X").

### State: `loading` — CoA/journal shimmer
Header + type filter stay; GL tree + journal rows render as `shimmer-skeleton`.

### State: `empty` — no accounting data
Illustration + "No accounting data yet"; a Create-GL-account CTA when CREATE_GLACCOUNT is held.

### State: `submitting` — posting
A balanced entry / reversal / closure / accrual posts via the durable outbox → `POST /v1/journalentries`; under maker-checker returns "Submitted for approval".

### State: `no-network` — offline cached
"Offline · showing cached accounting data" banner; a balanced entry queues, posts exactly-once on reconnect.

### State: `error` — fetch/post failed
Server error (400 unbalanced / invalid GL / closed period) + Retry; a rejected posting routes to `needs-attention-inbox`; a 403 → permission-drift refresh.

## Accessibility & Density Notes

- The balance gate is the finance-critical anchor: Post is disabled until debits==credits (>0); the delta is stated in words + red, not colour alone.
- Journal status chip carries text; a queued-offline variant shows un-synced postings.
- All GL codes + amounts in Roboto Mono for ledger alignment.
- Rejected postings route to `needs-attention-inbox`, never silently dropped.
