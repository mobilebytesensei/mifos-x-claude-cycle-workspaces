## Screen Intent

The read-only "what access do I hold" detail, drilled into from the capability engine (`view_permission_set`). Renders the resolved local PermissionSet grouped by permission grouping (portfolio, transaction_loan, accounting, authorisation, …), each grouping expandable to show its codes with a held/not-held marker, over a header carrying the role name, sha256 fingerprint (copyable), and held-vs-catalog totals. A search box filters codes. Fully offline from the cached code catalog.

- **Bottom navigation** — suppressed on this detail. **FAB** — none. **Offline banner** — n/a; renders from the cached catalog.

## Accessibility & Density Notes

- Held/not-held is conveyed by ✓/✗ glyph + text, never colour alone.
- Fingerprint is copyable in Roboto Mono so an operator can quote the exact resolution to support (drift diagnosis).
- Search + expandable groupings keep a 128-code catalog navigable for screen readers.
