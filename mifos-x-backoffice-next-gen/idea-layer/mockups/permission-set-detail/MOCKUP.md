## Screen Intent

The read-only "what access do I hold" detail, drilled into from the permission-capability-engine (`view_permission_set`). It joins the login-normalised local PermissionSet (held codes + umbrella short-circuits + sha256 fingerprint, read from `core/permissions` — no network) with the code catalog (`GET /v1/permissions`, cache-first) to render a grouped, searchable, held-vs-total view of exactly what access the signed-in user holds. Groupings mirror Fineract's own grouping taxonomy (portfolio, transaction_loan, transaction_savings, accounting, organisation, authorisation, …); each grouping expands to show its individual codes with a held (✓) / not-held (✗) marker. A header card carries the role name, the sha256 fingerprint (copyable, for CapabilityMap drift diagnosis with support), and the held-vs-catalog totals. A search box filters the code list across code + grouping. The screen is purely diagnostic and self-scoped — no mutation controls exist, and only the signed-in user's own resolved PermissionSet is ever shown. It renders fully offline once the code catalog has been cached once.

## Accessibility & Density Notes

- Held/not-held is conveyed by the ✓/✗ glyph **and** the `success`/`on_surface_variant` color pairing plus adjacent text — never color alone.
- The fingerprint is rendered in `font_family_mono` and is fully copyable so an operator can quote the exact resolved value to support when diagnosing a CapabilityMap drift or an access discrepancy.
- `psd_search` carries `accessibility_label: "Search permission codes within this set"`; `psd_copy_fingerprint` carries `accessibility_label: "Copy the permission set fingerprint to the clipboard"`; `psd_error_retry` carries `accessibility_label: "Retry loading the permission catalog"`.
- Search + expandable groupings keep a 128-code catalog navigable for screen-reader users without requiring a single unbounded scroll.
- All interactive targets (`psd_search`, `psd_grouping` rows, `psd_copy_fingerprint`, `psd_error_retry`) meet the 44dp minimum touch target (`touch_targets.minimum`).
