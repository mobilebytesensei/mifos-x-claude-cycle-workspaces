## Screen Intent

The parameterised report run + result surface, drilled into from the M14 Reports catalog and the M01 dashboard PAR tile. Resolves the report's parameter metadata + lookup options into a dynamic parameter form, runs the report via `GET /v1/runreports/{reportName}` on Run, and renders the result as a sortable table (or chart), with a CSV/PDF export to the platform share sheet. Read-only; gated on `READ_REPORT` / the report's own `READ_{reportName}`.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title = report name, back leading (drill-in from M14 / dashboard).
- **Bottom navigation** — suppressed on this detail. **FAB** — none. **Offline banner** — a cached same-param result resolves offline.

### State: `loading` — parameter shimmer
App-bar stays; the parameter form renders as `shimmer-skeleton` while parameter metadata + lookup options resolve.

### State: `empty` — zero rows
The report ran but returned zero rows for the chosen parameters → no-data panel with adjust-parameters guidance.

### State: `error` — resolve/run failed
Parameter metadata failed to resolve, or the run failed hard with no cache → error + `[ Retry ]` (`rr_error_retry` → `call_api`).

## Accessibility & Density Notes

- Read-only surface; Run gated on READ_REPORT / the report's own read permission.
- Result numerics in Roboto Mono so columns align; sort direction shown by a header glyph, not colour alone.
- Export hands off to the platform share sheet (CSV/PDF) — no in-app file handling.
- Empty (zero-row) result is distinguished from an error with adjust-parameters guidance.
