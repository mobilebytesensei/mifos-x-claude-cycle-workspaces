## Screen Intent

Single-loan drill-in from the M01 dashboard repayment tile and the M04 loan list. Loads `GET /v1/loans/{loanId}?associations=all` (summary, repayment schedule, transactions) cache-first through Store5 into a **summary header + tabbed body (Schedule · Transactions · Details)** with a permission-gated lifecycle action bar. Each action is evaluated against the PermissionSet **and** the loan status (Approve only on pending-approval, Disburse only on approved, Repayment only on active). Mutations route through the offline outbox with a durable idempotency key. `requires_permission: [READ_LOAN]`.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title = loan account no + product, back leading.
- **Bottom navigation** — suppressed on this detail. **FAB** — none (actions in the gated bar). **Offline banner** — reads from cache; a queued mutation shows an outbox badge.
