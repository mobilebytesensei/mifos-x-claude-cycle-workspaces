## Screen Intent

The scheduler console: a global scheduler on/off switch + the current **COB business-date** header, and the job list (cron, next/previous run, last-run status, active toggle). Selecting a row reveals the job detail + paged run-history. Scheduler commands (run-now / edit-schedule / enable-disable / toggle-scheduler / advance-business-date) are **server-side batch operations — ONLINE-ONLY, never queued to the offline outbox, no optimistic mutation**. Fineract job definitions are server-registered, so there is no create action.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title "Scheduler & Jobs", menu/back leading.
- **Bottom navigation** — visible as a module root. **Offline banner** — `offline_banner`: cached scheduler data; all mutating controls disabled ("requires connection").

### State: `loading` — job shimmer
Header + scheduler switch stay; job rows render as `shimmer-skeleton` (CACHE_FIRST_SWR).

### State: `empty` — no jobs
Illustration + "No scheduled jobs configured" — no create action (job definitions are server-registered).

### State: `submitting` — command in flight (online)
A scheduler command posts ONLINE with the control disabled + PENDING→SUBMITTED indicator; NEVER queued to the outbox — no optimistic mutation.

### State: `no-network` — offline cached
Persistent "Offline · showing cached scheduler data" banner; every mutating control DISABLED ("requires connection") because execution is online-only.

### State: `error` — fetch/command failed
Server error (400 invalid cron / 403 drift / run-failed-to-start) + Retry; a 403 → permission-drift refresh; a rejected run surfaces inline (no offline-queue triage).

## Accessibility & Density Notes

- Mutating controls are ONLINE-ONLY and disabled-with-reason offline — no optimistic scheduler mutation.
- Status chips carry text (Success/Failed/Running); a Failed chip is tappable to its run-history error.
- Cron + timestamps in Roboto Mono for legible schedule scanning.
