## Screen Intent

The sectioned loan/savings product create & edit form, drilled into from the M08 Products & Charges catalog. Renders the product's configuration in collapsible sections (Details · Terms · Interest · Charges · Accounting) from the Fineract `GET /{entity}/template` payload joined with the loaded product, each field editable with template-driven options and validation. Save persists a create or update via `POST/PUT /{entity}` (online-only + maker-checker, per the M08 config contract). Reads product + template cache-first through Store5.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title = product name (or "New product"), back leading (drill-in from M08).
- **Bottom navigation** — suppressed on this form. **FAB** — none; the primary action is a fixed **Save**. **Offline banner** — config edits are online-only (blocked offline per M08).

## Accessibility & Density Notes

- Collapsible sections keep a large product config navigable; each carries a header for screen-reader jumps.
- Config save is online-only + maker-checker (per M08) — never a silent deferred replay of a GL-affecting product change.
- Money/rate figures in Roboto Mono for aligned config review; min/max bounds shown inline.
