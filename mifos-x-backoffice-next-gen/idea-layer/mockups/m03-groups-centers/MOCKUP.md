## Screen Intent

The group-lending module: office-scoped **centers → groups** (nested) master list drilling into a group/center detail with members, group loans (GLIM), the meeting calendar, and per-member attendance capture. Management actions (activate, assign-staff, manage-members, save-collection-sheet, create) render only for the permissions the user holds; attendance + membership commands queue to the offline outbox for exactly-once replay. Reads CACHE_FIRST_SWR so the whole hierarchy is browsable offline.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title "Groups & Centers", menu/back leading.
- **Bottom navigation** — visible (Home · Clients · Collections · Sync) when entered as a module root.
- **FAB** — `create_group_center_fab` Teal, shown with CREATE_GROUP/CENTER.
- **Offline banner** — `no-network` shows a persistent "offline · cached" banner (`status_banner`).

## Accessibility & Density Notes

- Attendance toggle carries text state (present/absent/late), never colour alone.
- Save-attendance is one outbox batch — field capture works fully offline and replays exactly-once.
- Nested center→group hierarchy uses indentation + expand glyphs for screen-reader traversal.
- Management actions hidden (not greyed) without the gating permission — fail closed.
