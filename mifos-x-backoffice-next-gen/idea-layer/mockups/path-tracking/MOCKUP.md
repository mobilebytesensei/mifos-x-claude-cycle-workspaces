## Screen Intent

GPS field-visit route trail — records and visualizes the field officer's location track during a visit day. Accessible as a drawer root for **loan-officer-maker / collections-field-officer** personas. **Permission gate (§4.7 Tier 1): `requires_permission: READ_COLLECTIONSHEET`, `denied_behavior: hide-root` — the root is entirely absent from the nav roster for admin and super-user personas who don't hold a field-ops code.** Within the screen, all recording actions (start / pause / resume / stop / view session) are also gated to `READ_COLLECTIONSHEET` with `gray-out-info-dialog` on deny. Records GPS waypoints every ~5 seconds into a Room database session. Renders the trail as a polyline on a map (maps-compose / MapKit). Entirely offline — no Fineract API calls.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title "Path Tracking", drawer menu or back arrow.
- **Bottom navigation** — hidden (field-specific detail screen; not a bottom-tab module).

- **Snackbar** — `gps_signal_lost` / `storage_full` toasts shown during recording.

## Accessibility & Density Notes

- The GPS polyline on the live map has a `contentDescription` announcing route progress: "Recording: {distance} km, {duration} elapsed."
- Control bar floats over the map — high-contrast background (`on-surface`/`surface`) ensures legibility over varied map tiles.
- `stop_button` is `variant: destructive` with a confirm dialog before the session is closed and data is finalized.
- `session_row` carries `accessibility_label "View route session {date} · {duration} · {distance}"`.
- Permission denied flows (gray-out) show an info dialog before any navigation; users with limited permissions are never silently blocked without explanation.
