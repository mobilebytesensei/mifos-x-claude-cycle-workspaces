## Screen Intent

The Sync tab + preferences console: a sync-status banner (last-synced watermark + pending/failed counts), Sync-now / Pull-latest, a Needs-Attention entry (badged failed count), tenant/server switch, reference-cache clear + refresh, and device preferences (theme, language, biometric lock). Sync surfaces the `offline-sync-engine` outbox state read-only; logout clears the encrypted session and returns to the login gate.

### State: `idle` — at rest
Sync banner shows the last-synced watermark + 0 pending; all preference + server rows enabled; content-fresh.

### State: `syncing` — drain in flight
Sync banner shows per-command drain progress (PENDING→RETRYING→SUBMITTED); Sync-now / Pull-latest disabled until it settles.

### State: `empty` — fresh install
No outbox commands, no delta ever pulled → the banner offers a first full "Pull latest"; preferences at defaults.

### State: `needs-attention` — replays rejected
The Needs-Attention entry is badged with the failed count and routes to `needs-attention-inbox` for Retry / Edit / Discard triage.

### State: `error` — settings/outbox read failed
Error banner + Retry; cached preferences still render (never blank).

## Accessibility & Density Notes

- Preference toggles (theme/language/biometric) persist locally (persist_file) and carry text state.
- Clear-cache + logout are destructive + confirm; logout clears the encrypted session and returns to the gate.
- Sync banner surfaces pending/failed counts + connectivity in words + Roboto Mono numerics.
