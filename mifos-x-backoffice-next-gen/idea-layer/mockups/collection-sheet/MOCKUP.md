## Screen Intent

The field-officer collection capture surface (M06), drilled into from the M01 dashboard "today's route" tile. Generates the staffId-scoped sheet (`POST /v1/collectionsheet?command=generateCollectionSheet`) grouped **center → group → client** with per-loan installment dues and per-savings deposit dues, lets the officer capture **actual amounts** inline (defaulting to the due), toggle attendance, and **Save the whole route as one transactional batch** enqueued to the offline outbox with a durable idempotency key so an entire route captured with no signal replays exactly-once. `requires_permission: [READ_COLLECTIONSHEET]`.

## App Shell (resolved from `app-shell.yaml`)

- **Top app bar** — small M3, `surface`, title "Collection Sheet" + meeting date subtitle, back leading (drill-in from dashboard). Or entered via the Collections bottom-nav tab.
- **Bottom navigation** — visible when entered via the Collections tab (Home · Clients · **Collections** selected · Sync).
- **FAB** — none; the Save action is a fixed primary button at the sheet foot. **Offline banner** — capture is offline-first; a queued Save shows an outbox badge.

## Accessibility & Density Notes

- Currency fields are numeric-keyboard, prefilled with the due; officer edits only the deltas.
- Attendance toggle carries text state (present/absent/late), not colour alone.
- Save is one batch — an all-or-nothing outbox command; a partial network drop never leaves a half-saved route.
- Amounts in Roboto Mono keep totals column-aligned for fast reconciliation at meeting close.
