# Fineract REST API — Complete Capability Map (audit)

> **Live-verified** against `https://sandbox.mifos.community/fineract-provider/` — spec fetched from `GET /fineract-provider/fineract.json` → OpenAPI 3.0.3, **600 paths / 965 operations** (483 GET · 253 POST · 132 PUT · 97 DELETE). Instance: Apache Fineract `develop`, `1.16.0-SNAPSHOT`. `⚠︎K` = knowledge-grounded (command slugs the spec prose-lists, response internals, generic path enums, `/self/**`). This is the API the app must consume end-to-end.

## 0. Cross-cutting contract (every domain)

| Concern | Contract |
|---|---|
| **Base URL** | `{host}/fineract-provider/api/v1/...` (one op on `/v2`: `POST /v2/clients/search`) |
| **Tenant header** | `Fineract-Platform-TenantId: {tenant}` — global apiKey-in-header on EVERY op incl. `/authentication`. Sandbox: `default` |
| **Auth** | `basicAuth` + tenant. `POST /v1/authentication` → `base64EncodedAuthenticationKey` → `Authorization: Basic {key}` thereafter. OAuth2/OIDC optional |
| **Template pattern** | `GET /{entity}/template` (+ contextual `?clientId=&productId=`) returns field defaults + allowed-value lists → render forms FROM the template, never hardcode options. (Distinct from Excel `downloadtemplate`/`uploadtemplate` bulk import) |
| **Command pattern** | State transitions = `POST /{entity}/{id}?command={action}` + JSON body → `CommandProcessingResult{officeId,clientId,loanId,savingsId,resourceId,commandId,changes{}}` |
| **Maker-checker (4-eye)** | Maker-checkerable permission (toggled via `PUT /v1/permissions`) → mutating call is QUEUED not executed: 2xx with `commandId` + empty `changes`. Checker: `GET /v1/makercheckers` → `POST /{auditId}?command=approve\|reject` / `DELETE /{auditId}`. `GET /searchtemplate` for filters |
| **Pagination** | `offset` + `limit` + `orderBy` + `sortOrder` + per-entity filters. Paged envelope `{totalFilteredRecords, pageItems[]}`; unpaged = bare array |
| **Dates/numbers** | Every date-bearing mutation MUST send `dateFormat` + `locale` alongside date fields. Amounts are locale-parsed |
| **Associations/fields** | `?fields=a,b,c` partial; detail GET `?associations=all\|repaymentSchedule\|transactions\|...`, `?exclude=`, `staffInSelectedOfficeOnly` |
| **External-ID mirrors** | ~180 ops expose `.../external-id/{externalId}` path mirrors (clients, loans, loan txns/charges, savings + txns, offices, loan products, WC-loan family...) → **create with client-generated `externalId`, address resources BEFORE server assigns IDs** (offline-first keystone) |
| **Idempotency** | Loan-transaction POSTs honor `Idempotency-Key` header (safe repayment retry) ⚠︎K. Batch `requestId`+`reference` chain idempotently |
| **Errors** | 400 validation (`errors[]{developerMessage,defaultUserMessage,parameterName,args}`), 401/403 auth+permission, 404, 409 optimistic-lock, 403-on-auth = "Password reset required" |

## 1. Domains → operations (feature backlog)

- **Identity/Auth/Access** — `POST /v1/authentication` (response: `username,userId,base64EncodedAuthenticationKey,authenticated,officeId,staffId,organisationalRole,roles[],permissions[]`), `GET /v1/userdetails`, `POST /v1/password/forgot`; 2FA `/v1/twofactor` (+ validate/invalidate/configure); OIDC `/v1/tenants/{t}/oidc-config`; Users `/v1/users` (+ `/pwd`), Roles `/v1/roles` (+ `?command=enable\|disable`), Role-perms `/v1/roles/{id}/permissions` (PUT bulk), Permissions `/v1/permissions` (`?makerCheckerable=true`, PUT maker-checker toggle), Password policy `/v1/passwordpreferences`.
- **Organization/Reference** — `/v1/offices` (+external-id), `/v1/officetransactions`, `/v1/staff`, `/v1/holidays` (+`?command=activate`), `/v1/workingdays`, `/v1/currencies`, `/v1/funds`, `/v1/codes` + `/codevalues` (dropdown backbone), `/v1/paymenttypes`, `/v1/accountnumberformats`, `/v1/entitytoentitymapping`, `/v1/tellers` + `/cashiers` (+ `allocate`/`settle`/journals), `/v1/provisioningcategory`, `/v1/rates`, `/v1/grouplevels`.
- **Clients (KYC/360°)** — `GET /v1/clients` (filters: office/staff/status/legalForm/underHierarchy...), `POST /v2/clients/search`, `POST /v1/clients`, CRUD (+external-id), `GET /template`, lifecycle `POST /{id}?command=activate\|close\|reject\|withdraw\|reactivate\|undoRejection\|undoWithdrawal\|assignStaff\|unassignStaff\|proposeTransfer\|withdrawTransfer\|rejectTransfer\|acceptTransfer\|proposeAndAcceptTransfer`, `GET /{id}/accounts` (360°), `/obligeedetails`, `/transferproposaldate`, bulk import. Sub-resources: identifiers, addresses, familymembers, charges (`?command=paycharge\|waive`), transactions (`?command=undo`), images, documents, notes, collaterals, surveys.
- **Groups & Centers** — `/v1/groups` (+`?command=activate\|associateClients\|disassociateClients\|transferClients\|generateCollectionSheet\|saveCollectionSheet\|assignStaff\|close\|assignRole`), `/v1/centers` (+`?command=activate\|associateGroups\|generateCollectionSheet\|saveCollectionSheet\|close`), calendars/meetings (+`?command=saveOrUpdateAttendance`), `POST /v1/collectionsheet?command=generateCollectionSheet\|saveCollectionSheet` (individual — field-officer workhorse), GLIM `/v1/loans/glimAccount/{id}`, GSIM `/v1/savingsaccounts/gsim`.
- **Loans (full lifecycle)** — products `/v1/loanproducts` (+`/basic-details`, productmix, floating rates, charges catalog, delinquency ranges/buckets); accounts `/v1/loans` (`POST ?command=calculateLoanSchedule` = preview), `/template?templateType=individual\|group\|jlg`, lifecycle `?command=approve\|undoapproval\|reject\|withdrawnByApplicant\|disburse\|disburseToSavings\|undodisbursal\|assignloanofficer`; transactions `POST /{id}/transactions?command=repayment\|waiveinterest\|writeoff\|foreclosure\|recoverypayment\|creditBalanceRefund\|charge-off\|goodwillCredit\|chargeback...` (adjust/undo variants); schedule/reschedule `/v1/rescheduleloans` (`?command=approve\|reject`), tranches `/disbursements`, interest-pauses, delinquency-actions, post-dated-checks; parties: charges (`?command=pay\|waive`), guarantors, collaterals (+catalog `/collateral-management`), originators; **Working-Capital-Loans** vertical (90+ ops); COB `/catch-up`.
- **Savings/Deposits/Shares** — `/v1/savingsproducts`, `/v1/savingsaccounts` (lifecycle `?command=approve\|activate\|close\|calculateInterest\|postInterest\|block\|hold`), transactions `?command=deposit\|withdrawal` (+undo/reverse/modify/releaseAmount), on-hold funds, charges (`?command=paycharge\|waive\|inactivate`); term deposits `/v1/fixeddepositaccounts` + `/v1/recurringdepositaccounts` (lifecycle + `prematureClose`/`calculatePrematureAmount`, RD `updateDepositAmount`); interest-rate-charts + slabs; taxes (component/group); `/v1/accounttransfers` (+`?command=undo`, refundByTransfer), `/v1/standinginstructions` (+run history); shares `/v1/products/{type=share}`, dividends, `/v1/accounts/{type=share}` (`?command=approve\|activate\|applyadditionalshares\|redeemshares`).
- **Accounting** — `/v1/glaccounts`, `/v1/journalentries` (rich filters; `POST /{txnId}?command=reverse\|updateRunningBalance`, openingbalance, provisioning), `/v1/glclosures`, `/v1/accountingrules`, `/v1/financialactivityaccounts`, `/v1/provisioningcriteria` + `/provisioningentries`, `POST /v1/runaccruals`.
- **Admin/Config** — `/v1/configurations` (by id/name), **`/v1/datatables`** (dynamic custom-field schema CRUD + register/deregister + row CRUD one-to-one/one-to-many + advanced query — the custom-KYC engine), `/v1/entityDatatableChecks`, `/v1/fieldconfiguration/{entity}`, **scheduler** `/v1/jobs` (`?command=executeJob`, runhistory, business-steps, `/inline`), `/v1/scheduler` (`?command=start\|stop`), `/v1/businessdate`, external events/services, hooks (webhooks), instance-mode, caches, audits (`GET /v1/audits` full trail), maker-checker inbox, SMS/email campaigns + messages, report-mailing-jobs, document-templates (UGD mustache-merge), adhocquery, imports (bulk status), credit bureau, external-asset-owners.
- **Reporting/Search/Insights** — `GET /v1/runreports/{reportName}` (`R_*` params, `exportCSV`, output-type), `/v1/reports` CRUD, `GET /v1/search?query=&resource=` + `/advance`, `/v1/notifications` (poll + mark-read), SPM surveys `/v1/surveys` + scorecards, legacy PPI `/v1/survey`, likelihood/povertyLine, MIX/XBRL.
- **Cross-cutting** — **`POST /v1/batches?enclosingTransaction=true\|false`** (array of `BatchRequest{requestId,relativeUrl,method,headers,reference,body}`, `reference` chains steps via `$.resourceId`, all-in-one-transaction on failure rolls back — **the offline-sync keystone**); `/v1/{entity}/{id}/documents` (multipart + `/attachment` download); `/v1/{entity}/{id}/images`; `/v1/{resource}/{id}/notes`; interoperation (Mojaloop, 19 ops); `GET /actuator/health` + `/info` (no tenant header).
- **Self-service `/v1/self/**`** — ⚠︎K **ABSENT from this build's spec** (module disabled/excluded). If it stays off, customer flows proxy through the full API under a permission-scoped user.

## 2. Scale + sequencing

- **965 operations**; verb histogram 483 GET / 253 POST (incl. 40+ distinct `command=`) / 132 PUT / 97 DELETE. Loans domain alone ≈230 ops (incl. Working-Capital family 90+).
- **App boot sequence:** authenticate → hydrate reference data (offices, codes+codevalues, paymenttypes, currencies, funds, templates) → clients (create→activate→KYC) → products → origination (template→submit→approve→activate/disburse) → money movement (transactions, transfers, SI, collection sheets) → servicing (charges, reschedule, delinquency, holds) → accounting → admin → reporting/search/notifications → batch-driven offline sync.
