# App Flow Connections — Money Toolkit (kmp-project-template)

> Regenerated by `/idea sync` STEP 4 (2026-07-25). Grounded strictly in the 15
> `screens/{feature}/flow.yaml` nav edges + `ui.yaml` screen nodes — no invented
> screens or edges. **35 screen nodes** across **4 domains**. `Navigate` = push,
> `Back` = `popBackStackSafely()`, `Tab` = bottom-nav re-select, `Dialog` = in-screen
> overlay (no nav pop), `Mutate` = in-place state change (no navigation),
> `Planned`/`Pending` = target screen not yet shipped.

## Entry Points

- **NavHost start**: `home` — `AuthenticatedNavbarNavigationScreen` opens with `HomeDestination` as start destination after `auth_success`.
- **Bottom Navigation** (2 tabs): Home (`home`, default) · Profile (`profile`).
- **Crypto cluster entry**: home `Markets` tile → `coinMarkets`; then top-bar actions fan out to `watchlist` / `alerts-list`.
